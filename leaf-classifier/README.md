# 🌱 잎 분류 (Grok)

식물 사진을 올리면 **Grok(xAI)** 이 잎을 하나씩 찾아(**탐지**),
각 잎을 **성장중인 잎 / 성숙한 잎** 으로 **구분**하고 개수까지 세어 줍니다.

- **탐지 + 구분**: 각 잎의 위치(박스)를 찾고, `성장중인 잎`(어리고 연한 새 잎) /
  `성숙한 잎`(다 자란 진한 잎) 으로 분류합니다.
- ⚠️ **영역 마스크(분리)는 없음**: Grok은 Gemini와 달리 세그멘테이션 마스크를
  지원하지 않아, 잎 영역을 색으로 칠하지 않고 **박스로만** 표시합니다.

브라우저에서 xAI를 직접 부르면 **CORS로 막히기 때문에**, 같은 컴퓨터에서 도는
아주 작은 **프록시(`proxy.py`)** 를 함께 실행합니다. `proxy.py` 는 **파이썬 표준
라이브러리만** 쓰므로 `pip install` 같은 추가 설치가 없습니다.

---

## 1. xAI(Grok) API 키 발급 (유료)

1. https://console.x.ai 접속 → 로그인
2. API Keys 메뉴에서 키 발급 → `xai-...` 로 시작하는 키를 복사해 둡니다.

> ⚠️ xAI API는 **유료**입니다(무료 티어가 없거나 제한적). 사용량만큼 과금될 수 있어요.

## 2. 프록시 실행하기

터미널(맥: 터미널, 윈도우: PowerShell)에서 이 폴더로 이동한 뒤:

```bash
cd first-contributions/leaf-classifier
python proxy.py      # (맥/리눅스는 python3 proxy.py)
```

`🌱 잎 분류 프록시 실행 중 → http://127.0.0.1:8000` 이 보이면 성공입니다.

키는 두 가지 방법 중 하나로 넣을 수 있습니다:

- **(권장) 환경변수** — 키가 브라우저에 남지 않습니다. 프록시 실행 전에:
  ```bash
  export XAI_API_KEY="xai-여기에-본인-키"      # 맥/리눅스
  # 윈도우 PowerShell:  $env:XAI_API_KEY = "xai-여기에-본인-키"
  ```
- **웹 화면 입력** — 아래 3단계에서 키 칸에 붙여넣기.

## 3. 사용하기

브라우저에서 **http://127.0.0.1:8000** 을 엽니다.

1. (환경변수를 안 썼다면) **API 키** 칸에 `xai-...` 키를 붙여넣고 **"키 저장"**.
   - 키를 저장하면 **쓸 수 있는 모델 목록이 자동으로** 드롭다운에 채워집니다.
     **이미지(비전)를 지원하는 모델**을 골라야 합니다.
2. **잎 사진** 을 끌어다 놓거나 클릭해서 선택합니다.
3. **"🔍 분석"** 버튼을 누릅니다.
4. 잠시 후 결과가 표시됩니다:
   - 사진 위에 잎마다 박스가 그려집니다(초록=성장중, 주황=성숙).
   - 아래에 **성장중인 잎 / 성숙한 잎 / 전체** 개수가 나옵니다.
   - 표에서 각 잎의 구분과 위치를 확인할 수 있습니다.

프록시를 끄려면 터미널에서 `Ctrl + C`.

## 어떻게 동작하나요?

```
브라우저(http://127.0.0.1:8000)
   → 사진 업로드 → proxy.py (같은 컴퓨터) → xAI Grok 비전 모델
   → 각 잎의 박스 + 성장중/성숙 라벨(JSON) → 화면에 박스·개수 표시
```

`proxy.py` 는 브라우저의 `/api/models`·`/api/chat` 요청을 xAI로 중계할 뿐입니다.
(영역 마스크가 필요하면 Gemini 세그멘테이션 방식이 필요합니다.)

## 자주 묻는 문제

| 증상 | 해결 방법 |
|---|---|
| "프록시(proxy.py)로 실행해야 합니다" / "프록시에 연결하지 못했습니다" | `index.html` 을 그냥 열지 말고, 터미널에서 `python proxy.py` 실행 후 **http://127.0.0.1:8000** 으로 여세요. |
| "API 키가 없거나 올바르지 않습니다(401)" | 키 칸에 `xai-...` 키를 넣고 "키 저장", 또는 `XAI_API_KEY` 환경변수를 설정하고 프록시를 재실행. |
| "접근이 거부되었습니다(403)" | 결제 등록/사용 권한을 xAI 콘솔에서 확인하세요. |
| "모델을 찾을 수 없습니다(404)" | 모델 드롭다운에서 다른(비전 지원) 모델을 고르세요. |
| `Address already in use` | 8000번 포트가 사용 중입니다. `PORT=9000 python proxy.py` 처럼 다른 포트로 실행하고 그 주소로 접속. |
| 잎을 못 찾음 | 더 밝고 가까운 사진으로 시도. 잎이 서로 겹치면 인식이 어려울 수 있습니다. |
| 박스 위치가 어긋남 | VLM 특성상 박스가 정확하지 않을 수 있습니다. 정밀한 위치가 필요하면 전용 탐지 모델(YOLO 학습)이 낫습니다. |

## 파일 구성

```
leaf-classifier/
├── index.html   # 웹 UI (Grok 호출 + 화면 표시). 프록시로 /api/* 요청
├── proxy.py     # 로컬 중계 서버 (표준 라이브러리만, CORS 회피). index.html 서빙 + xAI 중계
└── README.md    # 이 문서
```

## 참고

- 이미지는 브라우저에서 최대 1024px로 줄여 전송합니다(속도·용량 절약).
- 성장 단계 기준(성장중 vs 성숙)은 크기·색·질감으로 모델이 판단하므로,
  결과는 참고용입니다. 정밀한 분류가 필요하면 직접 라벨링한 데이터로
  YOLO 모델을 학습시키는 방향으로 확장할 수 있습니다.
- `proxy.py` 는 요청을 xAI로 그대로 넘기는 얇은 중계층입니다. 키를 서버
  환경변수(`XAI_API_KEY`)로 주면 브라우저에 키가 저장되지 않아 더 안전합니다.
