# 🌱 잎 분류 (Grok)

식물 사진을 올리면 **Grok(xAI)** 이 잎을 하나씩 찾아(**탐지**),
각 잎을 **성장중인 잎 / 성숙한 잎** 으로 **구분**하고 개수까지 세어 줍니다.

- **탐지 + 구분**: 각 잎의 위치(박스)를 찾고, `성장중인 잎`(어리고 연한 새 잎) /
  `성숙한 잎`(다 자란 진한 잎) 으로 분류합니다.
- ⚠️ **영역 마스크(분리)는 없음**: Grok은 Gemini와 달리 세그멘테이션 마스크를
  지원하지 않아, 잎 영역을 색으로 칠하지 않고 **박스로만** 표시합니다.

설치할 것도, 서버도 없습니다. **HTML 파일 하나**를 브라우저로 열기만 하면 됩니다.

---

## 1. xAI(Grok) API 키 발급 (유료)

1. https://console.x.ai 접속 → 로그인
2. API Keys 메뉴에서 키 발급 → `xai-...` 로 시작하는 키를 복사해 둡니다.

> ⚠️ xAI API는 **유료**입니다(무료 티어가 없거나 제한적). 사용량만큼 과금될 수 있어요.
> 무료로 쓰고 싶다면 Gemini 버전을 쓰는 편이 낫습니다.

## 2. 실행하기

`index.html` 파일을 더블클릭해서 브라우저로 엽니다.
(크롬, 엣지, 사파리 등 아무 브라우저나 됩니다.)

## 3. 사용하기

1. **API 키** 칸에 발급받은 `xai-...` 키를 붙여넣고 **"키 저장"** 을 누릅니다.
   - 키는 **이 브라우저에만** 저장되고, 요청은 브라우저 → xAI로 직접 갑니다.
   - 키를 저장하면 그 계정에서 **쓸 수 있는 모델 목록이 자동으로** 드롭다운에 채워집니다.
     **이미지(비전)를 지원하는 모델**을 골라야 합니다.
2. **잎 사진** 을 끌어다 놓거나 클릭해서 선택합니다.
3. **"🔍 분석"** 버튼을 누릅니다.
4. 잠시 후 결과가 표시됩니다:
   - 사진 위에 잎마다 박스가 그려집니다(초록=성장중, 주황=성숙).
   - 아래에 **성장중인 잎 / 성숙한 잎 / 전체** 개수가 나옵니다.
   - 표에서 각 잎의 구분과 위치를 확인할 수 있습니다.

## 어떻게 동작하나요?

```
사진 업로드
   → Grok 비전 모델에 전송
   → 각 잎의 박스 + 성장중/성숙 라벨을 JSON으로 받음
   → 화면에 박스·개수 표시
```

별도 GPU/모델 설치 없이 Grok 비전 API 한 번의 호출로 **탐지 + 분류**를 처리합니다.
(영역 마스크가 필요하면 Gemini 세그멘테이션 버전을 쓰세요.)

## 자주 묻는 문제

| 증상 | 해결 방법 |
|---|---|
| "xAI 서버에 연결하지 못했습니다(CORS)" | 브라우저에서 xAI 직접 호출이 막힌 경우입니다. 중계용 작은 프록시 서버가 필요합니다(문의 주세요). |
| "API 키가 올바르지 않습니다(401)" | 키를 다시 복사해 붙여넣으세요. `xai-...` 형식이 맞는지 확인. |
| "접근이 거부되었습니다(403)" | 결제 등록/사용 권한을 xAI 콘솔에서 확인하세요. |
| "모델을 찾을 수 없습니다(404)" | 모델 드롭다운에서 다른(비전 지원) 모델을 고르세요. |
| 잎을 못 찾음 | 더 밝고 가까운 사진으로 시도. 잎이 서로 겹치면 인식이 어려울 수 있습니다. |
| 박스 위치가 어긋남 | VLM 특성상 박스가 정확하지 않을 수 있습니다. 정밀한 위치가 필요하면 전용 탐지 모델(YOLO 학습)이 낫습니다. |

## 참고

- 이미지는 브라우저에서 최대 1024px로 줄여 전송합니다(속도·용량 절약).
- 성장 단계 기준(성장중 vs 성숙)은 크기·색·질감으로 모델이 판단하므로,
  결과는 참고용입니다. 정밀한 분류가 필요하면 직접 라벨링한 데이터로
  YOLO 모델을 학습시키는 방향으로 확장할 수 있습니다.
- xAI API가 브라우저 직접 호출(CORS)을 허용하지 않으면 이 방식은 동작하지 않으며,
  그 경우 작은 중계 프록시(서버)를 추가해야 합니다.
