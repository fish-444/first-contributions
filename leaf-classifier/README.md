# 🌱 잎 성장 단계 분류기 (Gemini)

식물 사진을 올리면 **Gemini** 가 잎을 하나씩 **분리(SAM 역할)** 하고,
각 잎을 **성장중인 잎 / 성숙한 잎** 으로 **구분(YOLO 역할)** 해서 개수까지 세어 줍니다.

- **분리(SAM 역할)**: Gemini 세그멘테이션으로 각 잎의 영역(마스크)을 따로 떼어냅니다.
- **구분(YOLO 역할)**: 떼어낸 각 잎을 `성장중인 잎`(어리고 연한 새 잎) /
  `성숙한 잎`(다 자란 진한 잎) 으로 분류합니다.

설치할 것도, 서버도 없습니다. **HTML 파일 하나**를 브라우저로 열기만 하면 됩니다.

---

## 1. Gemini API 키 발급 (무료)

1. https://aistudio.google.com/apikey 접속 (구글 계정으로 로그인)
2. **"Create API key"** 클릭 → `AIza...` 로 시작하는 키가 생성됩니다.
3. 그 키를 복사해 둡니다.

> 무료 티어라도 사용량 한도가 있습니다. 한도를 넘으면 잠시 후 다시 시도하세요.

## 2. 실행하기

`index.html` 파일을 더블클릭해서 브라우저로 엽니다.
(크롬, 엣지, 사파리 등 아무 브라우저나 됩니다.)

## 3. 사용하기

1. **API 키** 칸에 발급받은 `AIza...` 키를 붙여넣고 **"키 저장"** 을 누릅니다.
   - 키는 **이 브라우저에만** 저장되고 외부로 전송되지 않습니다.
   - 키를 저장하면 그 계정에서 **쓸 수 있는 모델 목록이 자동으로** 드롭다운에 채워집니다.
     (모델명이 바뀌거나 특정 모델이 중단돼도 계속 동작합니다.)
2. **잎 사진** 을 끌어다 놓거나 클릭해서 선택합니다.
3. **"🔍 분석"** 버튼을 누릅니다.
4. 잠시 후 결과가 표시됩니다:
   - 사진 위에 잎마다 색이 칠해지고(초록=성장중, 주황=성숙) 박스가 그려집니다.
   - 아래에 **성장중인 잎 / 성숙한 잎 / 전체** 개수가 나옵니다.
   - 표에서 각 잎의 구분과 위치를 확인할 수 있습니다.

체크박스로 **마스크(분리 영역)** 와 **박스** 표시를 켜고 끌 수 있습니다.

## 어떻게 동작하나요?

```
사진 업로드
   → Gemini 세그멘테이션 (각 잎을 분리 = SAM 역할)
   → 각 잎을 성장중/성숙으로 분류 (= YOLO 역할)
   → 화면에 마스크·박스·개수 표시
```

원래 계획의 **SAM(분리)** 과 **YOLO(구분)** 두 단계를, 별도 GPU/모델 설치 없이
Gemini 비전 API 한 번의 호출로 처리합니다. (Gemini 2.5 는 바운딩 박스 탐지와
세그멘테이션 마스크 출력을 모두 지원합니다.)

## 자주 묻는 문제

| 증상 | 해결 방법 |
|---|---|
| "API 키가 올바르지 않습니다" | 키를 다시 복사해 붙여넣으세요. `AIza...` 형식이 맞는지 확인. |
| "무료 한도를 초과했습니다" | 잠시(1분 정도) 기다렸다가 다시 시도하세요. |
| 잎을 못 찾음 | 더 밝고 가까운 사진으로 시도. 잎이 서로 겹치면 인식이 어려울 수 있습니다. |
| 성장중/성숙 구분이 애매함 | 모델 드롭다운에서 `pro` 계열로 바꾸면 더 정확하지만 느립니다. |
| "이 모델은 더 이상 제공되지 않습니다" | 키를 저장하면 사용 가능한 모델이 자동으로 목록에 뜹니다. `🔄 모델 목록`을 눌러 새로 불러온 뒤 골라 주세요. |
