🌱 잎 분류

식물 사진을 올리면 Grok(xAI)이 잎을 하나씩 찾아(탐지), 각 잎을 성장중인 잎 / 성숙한 잎 으로 구분합니다. ※ Grok은 영역 마스크(분리)는 지원하지 않아 박스로만 표시됩니다.
1. Grok(xAI) API 키
이 앱은 로컬 프록시(proxy.py) 로 실행합니다. 요청은 브라우저 → 내 컴퓨터의 프록시 → xAI 로 갑니다. 키는 console.x.ai 에서 발급(유료). 서버에 XAI_API_KEY 를 설정했다면 이 칸은 비워둬도 됩니다.
키를 저장하면 그 계정에서 사용 가능한 모델을 자동으로 불러옵니다. 잎 분석에는 이미지(비전)를 지원하는 모델(예: grok 비전/최신 계열)을 고르세요.
2. 잎 사진 업로드
클릭하거나 이미지를 여기로 끌어다 놓으세요 (jpg / png / webp)
