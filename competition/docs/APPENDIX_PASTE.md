#### 3-2. end2end.onnx — 행동 15클래스 인스턴스 분할 (Mask R-CNN)

| 항목 | 내용 |
|---|---|
| 학습 데이터 | AI Hub 622 **폴리곤 라벨** (개체별 다각형 좌표 + 행동 15클래스) |
| 구조·환경 | Mask R-CNN (mmdet 3.3.0) · epoch 12 체크포인트(`pig_polygon_epoch12.pth`) |
| 변환 | mmdeploy 1.3.1 로 ONNX(opset 11) FP32 변환 · 입력 1333×800 keep-ratio — 변환 후에도 pytorch 경로와 병행 검증 |
| 성능 (정직한 기준선) | **bbox mAP 0.205 / segm mAP 0.192** — 학습에 쓰지 않은 200장(622 ts06, 2026-08-21 측정) |
| 클래스별 | 쓸 만함: Resting 0.633 · Eating 0.631 / 약함: Walking 0.261 · Searching 0.242 / 못 씀: Lying 0.058 · Sitting 0.015 · Standing 0.007 · Running 0.0 · Scrubbing 0.0 / 검증 불가(검증 표본 0): Suckling · Parturition · Drinking · Urinating · Defecating · Coughing |
| 학습 자료의 한계 | Parturition 은 학습 표본이 사실상 1건, Coughing 은 0건 — 이 두 클래스의 출력은 애초에 신뢰할 수 없어 사용하지 않는다 |
| 속도 | CPU 기준 pytorch 5.52초/장 · ONNX 6.7~7.5초/프레임(1080p, 16코어) |
| 사용 범위 | 프로그램은 **신뢰 클래스 4종(Resting·Eating·Walking·Searching)만** 구성비에 사용 — 코드에 `RELIABLE_CLASSES` 로 강제. 외부 영상 관통에서 구성비의 93.9~99.7%가 이 넷에 들어가 붕괴 클래스가 오염시키지 않음을 확인 |

**학습 과정 보고값(0.953)을 인용하지 않는 이유** — 그 값은 학습 자료와 검증
자료가 같은(train==val) 상태에서 잰 것이다. 처음 보는 200장에서 다시 재면
0.205 로 내려가며, 본 과제는 **낮더라도 처음 보는 자료에서 잰 값만** 쓴다.

### 4. 데이터 이용 고지

- **원자료 미포함** — AI Hub·Kaggle·스마트팜코리아 원자료와 외부 농장 영상은 제출물에 포함하지 않았으며, 기재된 수치는 전부 이들로부터 산출한 결과값이다.
- **비영리 조건 자료** — Edinburgh 데이터(CC BY-NC 4.0)는 분석·검증 목적으로만 사용했고, 해당 프레임이 포함된 화면은 첨부물에서도 제외했다.
- **농장 식별 정보 미기재** — 농장명·주소·허가번호 등은 산출물 어디에도 포함하지 않았다. 화면의 예시 농장은 실재하지 않는 구성이다.
- **경제 환산 인자** — 두당 마진의 단가 인자(지육률·지육가·사료요구율·비사료비)는 국내 통상 수준의 어림값으로 전부 조정 가능한 인자이며, 금액은 개선 순서 판단용이다.
- **수치 등급** — 기재된 모든 수치에 산출 근거 등급(실측·계산·유도·합성·지침)을 부여했다.
