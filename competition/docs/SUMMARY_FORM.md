**주요 기술**

- [주요 기술]
=> ① 번식 달력 — 정자·난자 생존창의 겹침을 적분해 교배 창을 시간 단위로 산출(하절기 배란 지연 +8.0h 보정 포함), 임신진단 3단계·재발 확인·분만 예정으로 연결
=> ② 교배 배정 — 근친계수 한도·웅돈 사용 상한 제약 아래 전체 배정의 인덱스 합을 최대화, 농장이 쓰는 관리표 서식 그대로 출력
=> ③ 영상 인식 — 자체 학습 탐지기(YOLOv8n, mAP50 0.659, 45,611 bbox) → IoU 추적 → 자세·행동 분류(CNN 0.732) → 시간창 구성비(분모 동반)
=> ④ 기준선 이탈 — 방·돈사 자신의 이력 분포 대비 로버스트 편차로 판정. 문턱은 상수가 아니라 목표 경보율(0.5~5%)에서 역산, 못 만들면 "경보 불가"를 명시
=> ⑤ 항등식 분해 — PSY를 회귀가 아니라 정의로 분해(202농장×4년에서 86.2%가 오차 0.05 이내 성립 확인), 격차를 두수·원/년으로 환산하고 돈사 병목의 이름을 지목

```

        │                                          │
```
