## 1. 한 줄 서사와 구조

> **발정을 놓치면 번식이 무너진다. 그런데 번식만 잡아도 농장은 안 산다 —
> 발정 탐지에서 출하까지 한 줄로 잇는다.**

구조는 **두 기둥 + 근거층**이다.

```
   기둥 1  발정·교배 관리          기둥 2  돈사 운영 관리
   달력이 카메라를 겨냥 →          돈사 스펙 → 수용 두수·병목 이름
   행동 구성비 → 자기 기준선 →     → 연간 출하 상한 → 가는 길 셋
   의심 순위(판정 아님)            + 환경 위험 알람
              ↑                              ↑
        근거층 — 국내 실측 466행 · 월별 179농장 · 케글/AI Hub 공개 데이터
```

**독창성의 핵심 셋** (별도 장이 없으므로 문서 전체에 녹인다):
1. **센서를 늘리는 대신 달력이 카메라를 겨냥한다** — 이미 아는 번식 일정이
   사전확률을 공짜로 준다.
2. **절대값이 아니라 자기 기준선** — 방·돈사마다 카메라·센서가 달라 절대값
   비교가 성립하지 않는다. 문턱도 발명하지 않고 자기 이력에서 역산한다.
3. **못 하는 것을 측정해서 명시한다** — 데이터 감사 자체가 분석 결과다.

## 2. 장별 집필 지침

### 1장. 축산 현장 문제 해결 등 제안서 목적 (2쪽)

공고 예시 항목 중 **(생산성향상)** 에 정렬한다("수정적기 예측으로 수태율
향상 및 공태기간 감소"가 우리 기둥 1 그 자체다). (종합) 항목에 두 기둥을
잇는 문장을 둔다.

쓸 수치: 재발 66.9% · 육성률 상위10% 93.9% vs 덴마크 93.3% · 하락 방어
2,976만원 · NPD ρ −0.737.

### 2장. 데이터 연계 (3쪽)

**데이터 표 하나로 시작**(§3-G). 그 다음 **데이터 감사를 분석 결과로**
제시한다 — 이것이 2장의 값어치다: 카메라 라벨 발견 · 외음부 대조군 0건 ·
원자료 중복 77.6% · 육성률 계산 오류 자체 발견 · 폴리곤 상한 8MB 로 측정해
10GB 회피.

### 3장. 알고리즘 개발 (5쪽 — 배점 50)

**□ 개발 과정 (~2쪽)**: 등급 체계 · 계산 재구현 금지(테스트 93개가 응답과
모듈 출력을 대조) · 교배 적기 겹침 적분 · 번식주기를 농장 값으로(불일치
4.3% 교정) · 용량 방향 역전 · 검증 방법론(개체 분리 GroupKFold · 못 본
카메라 LOVO · train==val 불인용 · 모수 복원).

**□ 구현 및 분석 (~3쪽)**: 어휘 4종 신고 → 분만징후 헤드가 막히는 것이
출력 · 기준선 층(IQR·경보율 역산·달력 게이팅) · 호흡수(행동 15종에 없는
것을 별도 원리로) · 환경 두 층 · **§3-C 안 되는 것 표를 그대로 싣는다**.

⬜ **CCTV 실증 자리**: 라벨 파일이 오면 within-room contrast 결과를 한
단락. 안 오면 "검증 설계와 성립 조건"까지만 쓴다 — **지어내지 않는다**.

### 4장. 도입 성과 (2.5쪽)

업무 활용방안(오늘 할 일 큐 · 작업 준수율 → 다음 배치 보정 · 영상 겨냥)과
현장문제 해결 방안(격차 분해 → 처방 순서표 · 여름 선별 처방). **금지 둘을
문서에 명시하고 지킨다**: 개입 효과 주장 없음 · 합산 없음.

### 5장. 활용실적 또는 계획 (2.5쪽 — 상용화 20점)

실적: 모듈 78개 · 뷰 24개 · API 30개 · 테스트 93개 · CSV 6종 · 외부 연결 0.
설치 요건을 수치로(군사 필수 14.0 vs 8.7px · 고정 카메라 필수).
계획 셋: ① 실농장 로그 1곳(열 이름만 맞으면 코드 변경 없이 합성→실측)
② Scrubbing 표본 → 분만징후 헤드 개방 ③ 재발 관문 CCTV 민감도 0.70→0.92 실증.

### 6장. [첨부] (쪽수 제외)

자료 출처 목록 · 대시보드 스크린샷 · 산출 CSV 예시 · 영상정리 규약 레코드 예시.

### B. 계절성 — 월별 179농장 `실측`

- 분만율 여름 교배 81.1% vs 겨울 84.1% = **−2.97%p**. 분만 시점으로 보면
  11월 최저라 안 보인다 — **임신 114일을 빼야** 7·8월이 드러난다.
- 부트스트랩 400회 중 90% 가 lag 3~4개월. argmax 는 3인데 **4를 유지**했다
  (3으로 바꾸면 간판 수치가 커지지만 생물학이 아니다).
- 농장별로 갈린다: 하위10% **−4.4%p** ~ 상위10% **+13.0%p**. 관측 분산의
  41%만 진짜 농장 차이(나머지는 표본 오차)인데 걷어내도 분포는 안 사라진다.
- 손실 상한(300두 환산): 중앙 **733만원** · 상위10% **3,172만원** · 67농장 합
  **9.7억원/년**. 겨울 수준 기준이라 장비값 뺀 순이익이 아니다.
- **취약도는 연간 성적으로 못 맞힌다**(PSY ρ −0.149) → 공통 처방이 아니라 선별 처방
- 무너지는 경로는 착상이다: 평균이유 −0.25두로 거의 안 움직이는데 임신사고
  구성이 **1차 재발 쪽으로 +8.0%p**(겨울 33.4% → 여름 41.4%) → 겨냥 시점은
  **교배 후 착상기(7~21일)**
- 원자료 **중복 77.6%** 를 감사·제거한 뒤 산출한 값이다.

### E. 돈사 운영 `계산`

- 예시 구성: 300두 설계가 실제 **299두**, 병목 **임신사**
- 생산량 항등식: `연간 출하 = 분만틀 × 채움률 × 복당 이유두수 × 육성률 × 연간 배치수`
  앞의 둘은 지어 놓은 것 → **가는 길이 정확히 셋**. 항이 곱해지므로 **합산 금지**
- 복당 이유두수 천장 **11.0두** = 자돈사 396자리 ÷ 분만틀 36. 목표값(12두)을
  상한으로 쓰면 허수 **594두·1.4억원**이 난다 — 자체 발견·교정
- 배치 간격: 3주 **288두**(병목 교배사) / 4주 266두(분만사) / 5주 **225두**(분만사)

- 개체 이력 배선: 유도값(교배 24.1 / 임신 54.5 / 분만 21.4%) → 실측으로 대체하니

## 4. 집필 규칙 — 본문에서 반드시 지킨다

1. **수치마다 등급을 붙인다.** 한 표에 실측과 합성을 섞지 않는다.
2. **합산하지 않는다.** 생산량 항등식은 항이 곱해지므로 "다 하면 +N두" 금지.
3. **개입 효과를 주장하지 않는다.** 격차의 **분해**까지다. 실농장 개입 실험 없음.
4. **부정 결과를 앞에 놓고, 뒤에서 철회하지 않는다.**
5. **빈 칸을 중앙값으로 채우지 않는다.**
6. **출처를 문장에 붙인다**(공고 요구사항이자 우리 규율).
7. 판정이 아니라 **의심**이라고 쓴다 — 영상 축의 출력은 "이 방을 오늘 먼저
   보라"까지다.
