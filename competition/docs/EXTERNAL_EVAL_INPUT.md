## 2. 확인된 것 (여기까지만 주장 가능)

**① 파이프라인 6단계 전부 산출됐다**

```
탐지 → 추적 → 활동량 → 구성비 → 기준선 → 의심 순위
미탐지 0프레임 · EMPTY 0 · NOT_RUN 0
```

**② 도메인 밖에서 탐지가 무너지지 않았다**

다른 농장·다른 카메라·처음 보는 영상에서 미탐지 0프레임입니다. 조건이
쉽지 않았습니다 — 1920×1080을 imgsz 512로 줄여 개체가 작아지는데
프레임당 31~33두로 밀집해 있었습니다. 창별 검출 수 539~769로 안정적입니다.

**③ 근거가 모자란 자리에서 층이 스스로 경보를 거부했다**

3개 방 × 3헤드 = 9자리 중 **2자리에서 컷을 만들지 않았습니다**
(`cut: null`). 억지 문턱을 세워 경보를 짜내지 않았습니다.

**④ 지속 조건이 실제로 경보를 막았다**

```
방1 win0  disease 1.491  over: true   alert: false
방2 win16 disease 1.996  over: true   alert: false
```

컷을 넘었는데 연속 2창 요구(`SUSTAIN=2`)가 걸려 경보가 나지 않았습니다.

**⑤ 분모가 끝까지 따라갔다**

산출 JSON의 창 60개(20창 × 3방) **전부**에 유효 프레임 수(`n_used`)와
검출 수(`n_det`)가 붙어 있습니다. 한 번도 끊기지 않았습니다.

**⑥ 이상으로 보이는 것을 이상으로 신고하지 않았다**

방2의 Eating이 10.8%로 다른 방(0.15% · 0.35%)의 30배였으나, 급이기가
화면에 드는 방 구조로 설명하고 이상으로 올리지 않았습니다.

## 3. 주장할 수 없는 것 (반드시 함께 적을 것)

**① 적중률을 내지 않았다**

```
negative_control : absent
hit_rate         : null
```

관측 기록(`observations.csv`)이 없어 대조할 정답이 없습니다. 사전등록
규약(등록 2-A) 성립 조건 — 방 ≥ 3(○) · 양쪽 있는 방 ≥ 2(✗) · 양성 창 ≥ 10(✗)
— 에 미달하여 규약대로 **"표본 부족으로 미검증"**입니다.

**② 사전등록 규약과 5건 어긋난다** (`prereg_conformant: false`)

| 이탈 | 규약 | 이 측정 | 사유 |
|---|---|---|---|
| 창 크기 | 30분 | 30초 | 방당 10분뿐 → 30분 창 0개 |
| 집계 단위 | 방-일 | 방-10분 | 하루치가 없다 |
| 헤드 게이팅 | 달력 창 | 없음 | 이유일·교배일 기록이 없다 |
| 기준선 | 채점과 분리 | 채점 창과 동일(in-sample) | 분리할 이력이 없다 |
| 경보율 대역 | 0.5~5% 역산 | **격자점 1/20 하나로 붕괴** | 창 20개에서 대역에 드는 경보 수가 1건뿐 |

**③ 방 간 순위 비교가 성립하지 않는다**

방3에 84~125px 활동량 프레임이 있습니다(방1·2는 최대 36px). 촬영 결함으로
보이며 `activity_px` 채널이 오염됐습니다. 방3이 두 헤드에서 1위인데 그
1위가 행동이 아니라 촬영에서 왔을 가능성이 큽니다.

**④ 경보 선택이 argmax와 구별되지 않는다**

창 20개에서 목표 대역에 드는 경보 수가 1건뿐이라, 컷은 각 방 최대 점수의
바로 아래 격자점으로 결정됩니다. 실제로 경보 5건이 **전부 그 방의 최대
창**이었습니다(5/5, 예외 없음).

| 방·헤드 | 컷 | 최대 점수 | 경보창 |
|---|---|---|---|
| 방1 estrus | 1.4 | 1.404 | 최대 창 |
| 방1 farrowing | 0.9 | 0.948 | 최대 창 |
| 방2 farrowing | 0.7 | 0.769 | 최대 창 |
| 방3 estrus | 1.7 | 1.769 | 최대 창 |
| 방3 farrowing | 1.3 | 1.322 | 최대 창 |

**⑤ 경보 0건을 "정상"으로 읽으면 안 된다**

이 층은 방의 **상태**가 아니라 자기 기준선 대비 **변화**를 잽니다. 10분 내내
균일하면 그 상태가 나빠도 경보가 나지 않습니다. 더구나 이 측정에서 컷
부재는 격자 해상도·하한에서도 발생합니다(4절).

**⑥ "실증"이라 쓰지 않는다**

n=1 농장 · 개입 없음입니다. **"동작 확인"** 또는 **"대조 측정"**입니다.

## 4. 찾아낸 결함 둘 — 이것이 이 실행의 수확이다

**결함 1 — 추적 진단이 원인을 잘못 지목한다**

`analyze_video.diagnose()`는 트랙/마릿수가 8을 넘으면 **"과분할 — 고정
카메라 필요"**를 출력합니다. 그러나 이 영상은 카메라가 고정입니다(흔들림
지표 2.24~3.25, ok 기준 ≤6). 실제 원인은 밀집 군사에서의 탐지 명멸입니다
— 레포 기준선이 3마리/프레임인데 이 영상은 31~33두로 10배 밀집입니다.

결과: 트랙/마릿수 9.0~13.8배, 트랙 길이 중앙 2.1~5.4초.
**개체 단위 활동량 누적 불가, 방 단위 집계만 성립.**

**결함 2 — 경보 컷 부재의 사유가 잘못 적힌다**

컷이 없는 두 자리에 "이력 산포가 없어 컷을 못 만든다"가 찍혔으나
**산포는 있었고 원인이 서로 달랐습니다.**

| 자리 | 실제 원인 | 근거 |
|---|---|---|
| 방2 estrus | z 격자(0.1)가 1·2위 간격(0.008)보다 굵다 | max 0.875 · 2위 0.867 · IQR 0.699 |
| 방3 disease | 최대 z 0.439가 격자 하한 0.5보다 낮다 | max 0.439 · IQR 0.762 |

**방2는 "문제없는 방이라 경보가 없는" 것이 아닙니다.** 방2는 farrowing
헤드에서 경보가 났고, 2위 점수만 0.75였다면 컷 0.8이 만들어져 estrus에서도
경보가 났을 것입니다 — 방의 상태를 하나도 바꾸지 않고서.

## 6. 5장에 넣을 문장 (이건 그대로 써도 됨)

> 학습에 사용하지 않은 외부 농장 영상 15클립(방 3개 · 연속 10분 · 총 30.1분)에서

> 없이 기본 설정 그대로 적용했으며 미탐지 프레임은 없었다. 다만 관측

> (등록 2-A, 2026-08-26)의 단위를 10분 녹화로는 만들 수 없어 규약대로
> "표본 부족으로 미검증"으로 남긴다. 이 과정에서 진단 메시지 두 곳이
