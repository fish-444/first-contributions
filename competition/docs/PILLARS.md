## 기둥 2 — 돈사 운영 관리

| 구성요소 | 어떻게 만들었나 | 사용 자료 | 등급 |
|---|---|---|---|
| 농장 등록 (돈사 스펙) | 번식사~비육사 방 수·자리·분만틀 + 방당 면적 입력, 단계 구간은 `growth_flow.STAGES` 일령 | 사용자 입력 + 법정 사육밀도(「축산법 시행령」[별표 1], 개정 2025. 3. 25. — `legal_density`) | 계산 + 지침(조문) |
| 수용 두수 · 병목 이름 | 두수→돈사 / 돈사→두수 양방향 역산. 예시 구성: 300두 설계가 실제 **299두**, 병목 **임신사** | 등록 스펙 | 계산 |
| 연간 출하 상한 | 상한 = 분만틀 × 채움률 × 복당 이유두수 × 육성률 × 연간 배치수. 복당 이유두수는 목표(12두)가 아니라 자돈사 수용력이 정한 천장(11.0두 = 396자리 ÷ 분만틀 36) — 목표값 사용 시 허수 594두·1.4억 발생을 자체 발견·교정 | 등록 스펙 + 농장 실적 | 계산 |
| 배치 이동 시뮬레이터 | 일 단위 배치 이동 400일, 7종 검사(AIAO·역류·세척생략·과밀·적체·무처소·유휴) 통과 필수. "전이 0회 = 정상" 오판을 자체 발견 후 무처소 검사 신설 | 등록 스펙 (합성 시나리오) | 합성 |
| 간격 what-if | 동일 스펙에 배치 간격을 재적용 — 3주 **288두**(병목 교배사) / 4주 266두(분만사) / 5주 **225두**(분만사), 2주 이하 불성립 | 등록 스펙 | 계산 |
| 개체 이력 → 단계 두수 | 번식주기 비율 유도값(교배 24.1 / 임신 54.5 / 분만 21.4%)을 실제 개체 이력으로 대체 — 유도 65두 뒤의 실측 75두, 교배사 자리 6두분 부족 발견 | 농장 개체 이력 CSV (`--herd`) | 실측(이력)+계산 |
| **돈사 환경 위험 알람** | 두 층: 위험(지침 위반 — 성장단계 7종 적온·습도, NH₃ 15ppm·H₂S 5ppm)과 주의(자기 기준선 편차). 돈사 간 비교는 \|z\| 로만, 지침 위반인데 편차 평소면 "센서 치우침·교정 확인" 주석. 제어 지시는 내지 않음 | 축산원 자료 2건(환절기 사양관리·쾌적한 사육환경) + 제공 지침표 + 센서 로그 | 계산 + 지침 |
